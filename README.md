# Arandu Ecosystem

Coleção de ferramentas, utilitários de sistema e aplicações escritas em **[Arandu](https://github.com/arandu-lang/arandu)** para demonstrar, estressar e expandir o ecossistema da linguagem.

## Projetos

| Projeto | Descrição |
| :--- | :--- |
| [`aratu`](./aratu) | Banco Key-Value embarcado append-only com índice em memória. |
| [`c2arandu`](./c2arandu) | Transpilador de código C para Arandu seguro e idiomático. |
| [`curumim`](./curumim) | Projeto do ecossistema Arandu. |
| [`guara`](./guara) | Micro-emulador RISC-V (RV32I) bare-metal determinístico. |
| [`ita`](./ita) | Ferramenta de hash SHA-256 de arquivos compatível com `sha256sum`. |
| [`jabuti`](./jabuti) | Motor de busca vetorial SIMD em memória por similaridade. |
| [`kandiru`](./kandiru) | Ferramenta streaming de consultas JSON baseada em arena. |
| [`katu`](./katu) | Buscador recursivo rápido de padrões de bytes (estilo `grep`/`rg`). |
| [`kururu`](./kururu) | Ray tracer em CPU com sombreamento Blinn-Phong e reflexões. |
| [`mutum`](./mutum) | Projeto do ecossistema Arandu. |
| [`poraque`](./poraque) | Visualizador hexadecimal e inspetor de binários ELF64. |
| [`sarapo`](./sarapo) | Servidor HTTP/1.1 leve para arquivos estáticos. |
| [`tuba`](./tuba) | Utilitário de compressão e descompressão em blocos estilo LZ4. |

## Requisitos

- Toolchain [Arandu](https://github.com/arandu-lang/arandu) instalada no `PATH`.
